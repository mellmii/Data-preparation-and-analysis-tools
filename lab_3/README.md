## Опис завдання
У даній лабораторній роботі проведено аналіз та візуалізацію багатовимірного датасету `League of Legends Professional Matches`. 
Виконано наступні етапи:
- **Data Cleaning:** Очищення даних від пропусків (видалення неінформативних колонок та заповнення медіанними/модовими значеннями).
- **Візуалізація:** Побудовано ряд графіків для аналізу ігрової статистики (KDA, Win Rate, GPM). Використано діаграми розсіювання (scatter plot), гістограми з розбиттям на 5 діапазонів, категоріальні діаграми (bar plot, box plot) та лінійні графіки (line plot).
- Побудовано багатовимірні візуалізації (з використанням кольору та розміру маркерів) для комплексного аналізу.

## Вимоги до системи
- **ОС:** Windows, macOS або Linux
- **Інтерпретатор:** Python 3.10 або вище 
- **Пам'ять:** Мінімум 4 ГБ ОЗП
- Редактор з підтримкою `.ipynb` (Jupyter Notebook)

## Інструкція із запуску та встановлення залежностей

Створіть та перейдіть у директорію проєкту:  
```
cd lab_03
```

Створіть віртуальне середовище:

```
python -m venv venv
```
Активуйте віртуальне середовище:

Для Windows:

```
.\venv\Scripts\activate
```
Для macOS/Linux:

```
source venv/bin/activate
```
Створіть файл requirements.txt у кореневій теці та додайте до нього лише необхідні для роботи бібліотеки:
```
Plaintext
pandas
matplotlib
seaborn
jupyter
```
Встановіть залежності проєкту:

```
pip install -r requirements.txt
```
Підготовка даних:
Завантажте датасет з професійними матчами Ліги Легенд та розмістіть файл league_of_legends_professional_matches.csv у корені теки лабораторної (цей файл ігнорується Git для економії місця).
Завантажити датасет з професійними матчами Ліги Легенд можна за цим посиланням:  
    [League of Legends Professional Matches на Kaggle](https://www.kaggle.com/datasets/tekpixo/league-of-legends-professional-matches)

Запустіть Jupyter Notebook:

```
jupyter notebook
```
Після запуску відкрийте файл з розширенням .ipynb для перегляду та виконання коду.
