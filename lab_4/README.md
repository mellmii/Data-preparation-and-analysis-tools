## Опис завдання
У даній лабораторній роботі реалізовано генерацію гармонічного сигналу, накладання шуму та його подальшу фільтрацію. 
Виконано наступні етапи:
- **Генерація та зашумлення:** Створення чистої гармоніки з можливістю налаштування амплітуди, частоти та фази. Додавання шуму з нормальним розподілом (налаштовується математичне сподівання та коваріація).
- **Фільтрація:** Застосування низькочастотного IIR-фільтра Баттерворта для очищення зашумленого сигналу (налаштовується частота зрізу).
- **Інтерактивна візуалізація:** Побудова графічного інтерфейсу за допомогою `matplotlib.widgets` та `tkinter`. Інтерфейс містить повзунки для зміни параметрів у реальному часі, чекбокси для перемикання видимості графіків та кнопки керування (Reset, Help). 

## Вимоги до системи
- **ОС:** Windows, macOS або Linux
- **Інтерпретатор:** Python 3.10 або вище 
- **Пам'ять:** Мінімум 4 ГБ ОЗП

## Інструкція із запуску та встановлення залежностей

Створіть та перейдіть у директорію проєкту:  
```
cd lab_04
```

Встановіть залежності проєкту:

```
pip install -r requirements.txt
```

Запустіть програму:

```
python ZPAD_LAB4.py
```

Після запуску відкриється вікно з інтерактивними графіками. Для отримання додаткової інформації щодо керування повзунками натисніть кнопку "Help" в інтерфейсі програми.
