## Опис оновлення (Лабораторна робота №7)
Програму **"silly camera 3000"**, створену в попередній лабораторній роботі, було суттєво оновлено. Додано інтеграцію із сучасними алгоритмами машинного навчання (модуль `cv::dnn`) для детекції об'єктів та реалізовано асинхронну обробку даних.

**Що нового:**
- **Детекція облич (AI/ML):** Додано новий режим (клавіша `F`), який у реальному часі знаходить обличчя на відео за допомогою нейромережі **ResNet-10** (SSD-архітектура).
- **Багатопотокова архітектура (Рівень 2 - 100%):** Щоб важкі обчислення нейромережі не блокували інтерфейс і відео залишалося плавним (30-60 FPS), програму розділено на два потоки:
  1. **Main Thread (UI):** Відповідає виключно за читання кадрів, малювання інтерфейсу (HUD) та рендер відео.
  2. **Worker Thread (Background):** Працює в межах нового класу `FaceDetector`. Чекає на нові кадри, виконує інференс (детекцію) та оновлює координати обличчя.
- **Синхронізація потоків:** Для безпечного обміну кадрами та координатами між потоками використано `std::mutex`, а для уникнення активного очікування процесора (busy waiting) застосовано `std::condition_variable`.
- **Штучне навантаження:** Для наочної демонстрації незалежності потоків, у фоновий потік додано затримку `std::this_thread::sleep_for` на 500 мс. Рамка обличчя оновлюється кожні півсекунди, при цьому сам відеопотік не зависає і залишається ідеально плавним.

## Базовий функціонал (З Лабораторної №6)
- **Інтерактивні режими обробки (1-6):** Нормальний режим, Інверсія, Розмиття, Фільтр Кенні, **Glitch Effect** та **Neon Void**.
- **Взаємодія з мишею:** Малювання кастомних фіолетових сердечок на екрані (ЛКМ) та їх очищення (ПКМ).
- **UI Елементи:** Кастомний чорний HUD з інструкціями та інтерактивний повзунок яскравості.

## Структура проєкту
Програма має модульну архітектуру:
- `include/` — заголовні файли класів (`CameraProvider`, `Display`, `FrameProcessor`, `KeyProcessor`, `FaceDetector`).
- `src/` — реалізація логіки класів та точка входу `main.cpp`.
- Коренева директорія містить конфігурацію `CMakeLists.txt` та скрипти автоматизації.

## Вимоги до системи
- **ОС:** Linux (рекомендовано сімейство Debian/Ubuntu).
- **Апаратне забезпечення:** Наявність підключеної веб-камери.
- **Мережа:** Підключення до інтернету для першого запуску `preinstall.sh` (завантаження ваг нейромережі).
- **Залежності:** `build-essential`, `cmake`, `libopencv-dev`, `wget` (встановлюються автоматично).

## Інструкція із запуску та встановлення залежностей

Проєкт містить зручні Bash-скрипти для автоматизації налаштування, збірки та запуску на чистій системі.

1. **Клонуйте репозиторій та перейдіть у директорію проєкту:**
   ```
   git clone [https://github.com/mellmii/Data-preparation-and-analysis-tools.git]
   Data-preparation-and-analysis-tools/lab_7
   ```
2. **Встановіть залежності та завантажте моделі нейромережі:**
Скрипт автоматично встановить OpenCV та завантажить необхідні файли deploy.prototxt і .caffemodel за допомогою wget.
(Скрипт запросить пароль адміністратора sudo)

 ```
./preinstall.sh
 ```

3. **Скомпілюйте програму:**
   Скрипт автоматично створить директорію `build`, згенерує `Makefile` через CMake та збере проєкт.
   ```
   ./build.sh
    ```
4.**Запустіть програму:**

 ```
./run.sh
 ```

*(Примітка: Переконайтеся, що всі три скрипти мають права на виконання: `chmod +x *.sh`)*
