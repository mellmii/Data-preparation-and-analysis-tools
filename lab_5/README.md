## Опис завдання
У даній лабораторній роботі створено інтерактивний веб-додаток за допомогою фреймворку `Streamlit` для аналізу вегетаційних індексів (VCI, TCI, VHI) на основі історичних даних NOAA по областях України. 

Виконано наступні етапи:
- **Інтерактивні фільтри:** Реалізовано вибір індексу, області, а також налаштування діапазону років та тижнів за допомогою випадаючих списків (dropdown) та повзунків (slider).
- **Сортування та керування станом:** Додано чекбокси для сортування даних (за зростанням/спаданням) із захистом від конфліктів, та кнопку  для швидкого повернення фільтрів до початкового стану.
- **Візуалізація (Plotly):** Дані розподілені на три окремі вкладки:
  1. Таблиця з відфільтрованим датафреймом.
  2. Інтерактивний лінійний графік динаміки обраного індексу для конкретної області за вибраний часовий інтервал.
  3. Стовпчикова діаграма для порівняння середніх значень індексу обраної області з усіма іншими областями (із візуальним виділенням обраної області).
- **UI/UX Дизайн:** Додаток оформлено у кастомній кольоровій темі (налаштовано через `.streamlit/config.toml`).

## Вимоги до системи
- **ОС:** Windows, macOS або Linux
- **Інтерпретатор:** Python 3.10 або вище 
- **Пам'ять:** Мінімум 4 ГБ ОЗП

## Інструкція із запуску та встановлення залежностей

1. Створіть та перейдіть у директорію проєкту:  
```
cd ZPAD_Lab5
```

Переконайтеся, що папка data із завантаженими .csv файлами знаходиться у корені проєкту (поряд із файлом додатку).

Створіть та активуйте віртуальне середовище:

```
python -m venv venv
```
Для Windows:
```
.\venv\Scripts\activate
```
Для Linux/macOS:
```
source venv/bin/activate
```

Встановіть залежності проєкту:

```
pip install -r requirements.txt
```

Запустіть програму:

```
streamlit run app_for_lab_5.py
```
(Примітка: якщо основний файл скрипта має іншу назву, замініть app_for_lab_5.py на відповідну).
