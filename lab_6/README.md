# Лабораторна робота №6
# Засоби підготовки та аналізу даних: Обробка відеопотоку за допомогою OpenCV

**Виконала:** Городиська Анна ФБ-44

## Опис завдання
У даній лабораторній роботі створено інтерактивну C++ програму **"silly camera 3000"** для захоплення та обробки відеопотоку з веб-камери в реальному часі з використанням бібліотеки `OpenCV`. Програма побудована за модульною архітектурою з розділенням логіки на окремі класи.

Виконано наступні етапи:
- **Захоплення відео:** Реалізовано безперервне читання кадрів з камери за допомогою класу `CameraProvider`.
- **Інтерактивні режими обробки:** Додано 6 унікальних режимів фільтрації, які перемикаються клавішами:
  1. Нормальний режим.
  2. Інверсія кольорів (`bitwise_not`).
  3. Розмиття (`GaussianBlur`).
  4. Фільтр Кенні (виділення контурів).
  5. **Glitch Effect:** кастомний ефект розсування RGB-каналів (зсув червоного каналу).
  6. **Neon Void:** кастомний ефект темної атмосфери зі світінням контурів у стилістиці *Hollow Knight*.
- **Взаємодія з мишею:** Реалізовано можливість малювання кастомних фіолетових сердечок на екрані лівим кліком миші та їх очищення правим кліком.
- **UI Елементи:** Створено кастомний чорний HUD (інтерфейс) у верхній частині екрану для відображення інструкцій, а також додано інтерактивний повзунок (Trackbar) для плавного керування яскравістю відеопотоку.

## Структура проєкту
Програма має модульну архітектуру (кожен модуль — окремий клас в `.hpp` та `.cpp` файлах):
- `include/` — заголовні файли класів (`CameraProvider`, `Display`, `FrameProcessor`, `KeyProcessor`).
- `src/` — реалізація логіки класів та точка входу `main.cpp`.
- Коренева директорія містить конфігурацію `CMakeLists.txt` та скрипти автоматизації.

## Вимоги до системи
- **ОС:** Linux (рекомендовано сімейство Debian/Ubuntu) для повної сумісності Bash-скриптів.
- **Апаратне забезпечення:** Наявність підключеної веб-камери.
- **Залежності:** `build-essential`, `cmake`, `libopencv-dev` (встановлюються автоматично).

## Інструкція із запуску та встановлення залежностей

Проєкт містить зручні Bash-скрипти для автоматизації налаштування, збірки та запуску на чистій системі.

1. **Клонуйте репозиторій та перейдіть у директорію проєкту:**
   ```
   git clone [https://github.com/mellmii/Data-preparation-and-analysis-tools.git]
   Data-preparation-and-analysis-tools/lab_6
   ```
2. **Встановіть усі необхідні залежності та бібліотеки OpenCV:**
(Скрипт запросить пароль адміністратора sudo)

 ```
./preinstall.sh
 ```

3. **Скомпілюйте програму:**
   Скрипт автоматично створить директорію `build`, згенерує `Makefile` через CMake та збере проєкт.
   ```
   ./build.sh
    ```
4.**Запустіть програму:**

 ```
./run.sh
 ```

*(Примітка: Переконайтеся, що всі три скрипти мають права на виконання: `chmod +x *.sh`)*
